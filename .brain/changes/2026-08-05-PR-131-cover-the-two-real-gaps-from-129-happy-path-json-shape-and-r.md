## Decisions & rationale

- **A test at the contract boundary outlives a test at the function boundary.** The `date_source`
  allowlist is the concrete case: `runDate`'s own tests would go with a rewrite; this one would not.
  Worth preferring wherever a defect is about what a tool *reports* rather than how it computes.

  an artefact — prose, a CLI's behaviour, a test file — made from adjacent context rather than by
  reading the artefact. All three cost a round trip; none was caught by review.
