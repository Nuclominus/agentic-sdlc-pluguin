# PR #208 — branch and staleness preflight before --resume

> `feat` · merged 2026-09-23 · by @Nuclominus

## Summary

Adds a preflight gate to `sdlc:run --resume` (`plugins/sdlc/tools/run/reentry.mjs`,
`resumePreflight()`): resuming a run now HALTs if the current git branch doesn't match the
branch the run was started on, and prompts resume/start-fresh/abort if the newest checkpoint
is older than a configurable threshold (default 6h, `--max-age-hours`). This closes the gap
that motivated the comparison against `claude-sdlc`'s resume flow — this repo's `--resume`
previously had no branch or staleness check at all. A new `resume-check` CLI subcommand
exposes the same preflight standalone for scripting/CI use, and the orchestrator's
`pipeline-orchestrator` SKILL.md Step 2 now runs it before resuming, deleting stale
checkpoints on a "start fresh" choice instead of merely claiming to.
