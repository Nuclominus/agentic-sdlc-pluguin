# PR #190 — embed framework providers

## Summary

The seven additive Android framework plugins (Retrofit, Ktor, Room, DataStore-Proto, Dagger/Hilt, Koin, WorkManager) are now embedded as rows in `android-foundation`'s `frameworks` array. This is a **breaking change** that reduces the marketplace from 11 to 4 entries and requires dependency-gated activation to be preserved in the resolver. ADR-0026 supersedes ADR-0002, recording the design rationale. Skill ids change (e.g. `retrofit-plugin:retrofit-conventions` → `android-foundation:retrofit-conventions`), with `/sdlc:doctor` offering migration for existing installs.
