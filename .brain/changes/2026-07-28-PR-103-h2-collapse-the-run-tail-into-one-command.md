# PR #103 — H2 — collapse the run tail into one command

> `feat` · merged 2026-07-28 · by @Nuclominus

## Summary

The end of a run was three mandated invocations across six prose sub-steps: the clock arithmetic on
`.checkpoint/_started_at`, `usage/cli.mjs enrich`, and `report/cli.mjs report`. This PR replaced all
of it with one shipped command, `tools/run/cli.mjs finish <slug>`.

The reason is measured, not stylistic. [[planning/h1-compliance-auditor]] found that compliance
tracks **how many separate things an instruction asks for**, not how firmly it asks: single-command
steps scored 87–100%, while `5-clock` — read the anchor, subtract, render with a BSD-vs-GNU `date`
fallback — scored **67%**, the worst in the set, while carrying the most emphatic prose in the whole
file.

Two things went further than the item as written. `clock.mjs` became the **sole writer** of
`started_at` / `completed_at` / `wall_clock_seconds`, so the orchestrator no longer authors the run
clock at all; rendering through `Date` took the portability hazard out with the step. And `--session`
was not moved but **deleted** — the enricher already recovers the orchestrator session from a phase
transcript, so the model can no longer supply the wrong one, which is how a worktree-isolated run
once priced its overhead at $0.55 instead of $5.21.

Contracts gained an `until` date so the three replaced ones could retire without either deleting the
baseline or failing forever against a procedure that no longer exists. That is what made the result
checkable: the historical rates **reproduce exactly** after the collapse — 82.3% over the same 15
runs.

Measured: mandated invocations in the run tail 3 → **1**; `SKILL.md` 2509 → **2436** lines; live
contracts 6 → **4**.

The honest limit, recorded at the time and still true: `5b-finish` reports `n=0`, so H2's own effect
is **not yet measured** and cannot be until runs exist on the new version.
