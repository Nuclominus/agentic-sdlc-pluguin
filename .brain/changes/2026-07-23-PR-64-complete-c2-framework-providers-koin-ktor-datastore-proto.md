## Decisions & rationale

- Implements three new instances of the **Framework Provider Pattern** —
  [[decisions/ADR-0002-framework-provider-pattern]]. Each is `kind: framework`, ships **no agents**,
  and only injects the `development` + `security` phases plus a conventions skill and R8/ProGuard
  snippet; it activates only when its `dependency` is detected. Koin (`di`) and Ktor (`network`)
  **coexist** with the existing `dagger-plugin` / `retrofit-plugin` on the same aspect — the
  orchestrator does not resolve a single winner per aspect; in practice a project uses one.
- **`kotlinx.serialization` was deliberately deferred.** The functional-aspect taxonomy
  (`network / persistence / di / ui / background / analytics / architecture`) has no `serialization`
  category; whether to add one or fold it into `network` is an open decision (candidate future ADR),
  so it was not built in this batch.
- Koin's R8 snippet is intentionally **minimal + a note** (runtime DI, no codegen — no keep rules
  needed beyond the Koin-Annotations/KSP exception).
