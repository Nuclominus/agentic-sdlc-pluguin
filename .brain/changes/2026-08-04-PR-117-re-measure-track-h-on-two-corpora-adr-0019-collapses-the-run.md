## What was measured

The corpus doubled. [[planning/h1-compliance-auditor]] had one downstream project; this run adds a
second, previously unaudited one, for **28 auditable runs, 6 excluded**.

| rate | contract | n | was (2026-07-29) |

| 67% | `3d-1b-phase-cost` | 9 | 40% · n=5 |

Live-contract overall **92.9%**. Two findings, pulling in opposite directions:

- **H4's threshold is met and its sample size is not.** The gate said *"if compliance has not moved
  above ~90%, H4 is the answer"*; it has, and `5b-finish` — the contract that replaced the 67%
  `5-clock` — is 5/5, the first real evidence [[decisions/ADR-0014-the-run-tail-is-one-command]]
  worked. But only five runs are on the new tail against the ~10 asked for. Recorded as **leaning
  against the rewrite, still gated**.
- **The cardinality finding weakened.** `3d-1b-phase-cost` moved 40% → 67% as its denominator went
  5 → 9. It survives as the only failing live contract, but "collapse cardinality, not lines" is now
  directional rather than established.

The start window was re-derived per run: median 34 turns / 18 calls / **$2.05 = 17.0% of run cost**,
worse than the $1.42 previously estimated. Splitting it at the `_started_at` boundary separated the
part that can collapse (Steps 0→1d: 24 turns, $1.31, **11.8%**) from Step 2's workspace creation,
which stays — and **corrected this PR's own ADR from ~17% to ~11.8%** before it was proposed.

## Decisions & rationale

- **[[decisions/ADR-0019-the-run-start-is-one-command]]** (`proposed`) — Steps 0→1d become one
  shipped command. Symmetric to [[decisions/ADR-0014-the-run-tail-is-one-command]]: the tail
  collapsed because compliance tracks how many things an instruction asks for; the start collapses
  because cost tracks how many turns the model spends discovering what a program returns in one.
  Implementation spec: [[planning/h5-d2-start-resolution-command]].
- Guardrails written into the decision rather than left implicit: the prose is **deleted, not moved**
  to a just-in-time fragment (that shape measures 40–67%); per-phase base prompts stay inside
  [[decisions/ADR-0008-read-discipline-contract]]'s stable prefix; and the ADR states explicitly that
  it does **not** close the H4 gate, so shipping it cannot later be misread as evidence about H4.
- The manifest root must be a parameter — established by a check that first looked like a prose
  defect and was not: `resolveStack()` attached `datastore-proto` to a project no real run resolved
  it for, because the lint globs the marketplace tree while the consumer's cache has no such plugin.
