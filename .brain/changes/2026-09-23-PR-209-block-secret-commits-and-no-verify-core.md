## Summary

- New `PreToolUse`/`Bash` hook `plugins/sdlc/hooks/pre-commit-guard.sh` in the core `sdlc` plugin: denies staged secrets (AWS key IDs, private key blocks, assigned key/secret/token/password literals) and `--no-verify` on `git commit`/`git push`/`gh pr create`.
