# PR #107 — H6 — a Stop hook seals a finished run

> `feat` · merged 2026-07-28 · by @Nuclominus

## Summary

A `Stop` hook (`plugins/sdlc/hooks/seal-run.sh`) seals a run the orchestrator finished but did not
seal. H2 moved the run tail from prose to one command — one chance to deviate instead of three — but
a command is still a command someone has to type. This is the net under it.

**The gate is completeness, not recency**, because recency cannot tell a paused run from a finished
one. A run is sealable only when every phase in the resolved DAG carries a terminal checkpoint,
`_telemetry.json` exists, and `.checkpoint/_sealed` does not. That gate was chosen by measurement:
run over the 19-run downstream corpus it opens for **10** runs — including
`native-chat-engine-s2-thread-list`, the [[decisions/ADR-0012-unpriced-runs-must-not-render-a-cap-verdict]]
incident run and the case the hook exists for — and stays shut for the three runs
[[planning/h1-compliance-auditor]] had named as carrying most of the damage. Six runs predate
`.checkpoint/_run.json` and are permanently out of reach: the gate **fails closed**.

**The clock comes from the run's newest `mtime`**, not the wall clock. Sealing is late by
construction, and `wall_clock_seconds` is `now - anchor`, so the real clock would bill a run for the
time the user spent chatting afterwards — ADR-0014 priced that at 3522s → 11144s and $12.81 →
$13.71. `opts.now` was already a test seam; H6 feeds a machine value through it.

**The hook exits 0 unconditionally.** For `Stop`, exit code 2 is not "error" — it blocks the agent
from stopping and feeds stderr back as an instruction. A sealing net that can trap a user in a loop
is worse than no net. A test pins this.

Sizing the gate forced a move: the completeness rule (`loadCheckpoints` / `computeReentry` /
`resolveWorkspace`) lived in the repo-root `sdlc-lint`, which does not ship, while the hook runs on a
consumer's machine through `${CLAUDE_PLUGIN_ROOT}`. It moved to `tools/run/reentry.mjs`, and
`lib/resume.mjs` became a re-export shim — so `--resume` and the seal gate share one definition of
"done" rather than two that can drift.

`sealed_by` records which path sealed a run, and `sdlc-lint compliance` prints a `seal:stop-hook`
line **beside** the contract rates, never inside them. The contract `5b-finish` is deliberately
unchanged: a hook leaves no `tool_use` block, so it is invisible to a transcript auditor, and the
rate must keep measuring the *model*. The share reads `n/a` rather than `0%` when nothing recorded a
sealer — a zero would assert the net never fired when the truth is that nobody was looking.

Limits, stated rather than buried: a hook enforces **state, never intent**; it cannot fire if the
session is killed before `Stop`; it repairs after the fact, so it does nothing for the 3d-1b cap
gate, which spends its numbers mid-run; and if every phase completes but the model dies **before**
assembling `_telemetry.json`, there is nothing to seal.
