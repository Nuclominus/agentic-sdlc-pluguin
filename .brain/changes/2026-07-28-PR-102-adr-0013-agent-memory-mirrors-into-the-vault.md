# PR #102 — ADR-0013 — agent memory mirrors into the vault

> `docs` · merged 2026-07-28 · by @Nuclominus

## Summary

Two knowledge stores exist for this repo and only one is the SSOT. `.brain/` is versioned, reviewable, and visible to every contributor. Alongside it the agent keeps a private file-based memory outside the repository.

An audit across twelve memories on 2026-07-28 found one finding held **only** in agent memory — that
in subagent-driven development here, every review finding traced to a defect in the authored plan
rather than to an implementer deviating from it. It had been true and useful for three days and was
invisible to anyone reading the repository. This PR closes that side door and backfills the one
uncovered lesson.

## Decisions & rationale

Implements [[decisions/ADR-0013-agent-memory-mirrors-into-the-vault]] and records
[[decisions/ADR-0016-amend-the-spec-and-the-plan-together]].

- **A second knowledge store is fine; a second *authoritative* store is not.** Agent memory buys
  automatic recall at session start, which the vault does not — so the answer is mirroring, not
  deletion. The same "one store must be authoritative" reasoning the repo already applied to cost in
  [[decisions/ADR-0005-transcript-derived-cost]].
- **The mirror is not a copy-paste.** The vault note carries the reasoning and the evidence; the
  memory carries the short recall form and how to apply it. That asymmetry is what makes the vault
  copy the reviewable one.
- **`user`-type memories are deliberately exempt** — they describe the person, not the project, and
  mirroring them would put personal preferences into a shared repository.
- **Numbered 0016, not 0014.** ADR-0014 and ADR-0015 were already taken on `track-h`, unmerged at
  the time; picking the next free number avoided a collision that would only have surfaced at merge.
- **Based on `develop`, not `track-h`** — this is a repo-wide convention rather than part of the
  instruction-fidelity track, and keeping it off that branch preserves `develop..track-h` as a clean
  read of the track.
