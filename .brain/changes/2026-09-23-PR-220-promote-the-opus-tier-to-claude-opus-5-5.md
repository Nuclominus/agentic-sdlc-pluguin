# PR #220 — promote the opus tier to Claude Opus 5.5

> `chore` · merged 2026-09-23 · by @Nuclominus

## Summary

The dispatched `opus` tier now resolves to Claude Opus 5.5 (`claude-opus-5-5`) instead of Opus 5,
repriced to $4.00 input / $0.20 cached / $20.00 output per million tokens. `claude-opus-5` stays in
the registry as a pin-only reference entry (`opus-5`), so telemetry can still price runs that
recorded it. Dry-run previews for an `opus` dispatch drop from about $0.95 to about $0.62.

Nothing in the pipeline is exposed to Opus 5.5's breaking changes (thinking cannot be disabled,
`effort` defaults to `medium`, forced `tool_choice` returns a 400): every agent sets `effort`
explicitly, and dispatch goes through the `Agent` tool by tier name with no `thinking` or
`tool_choice`.

Caveat: `estimation_baselines.opus` is **provisional**. Its tokens were measured on Opus 5 and no
run has been measured on 5.5. The estimator drift test now prices each baseline at the model its
median was measured on (`MEASURED_ON`), so it checks the token shape only. The `fable` baseline
inherits the opus shape and is affected the same way. The orchestrator's illustrative telemetry
example was updated and `dist/antigravity` re-emitted.
