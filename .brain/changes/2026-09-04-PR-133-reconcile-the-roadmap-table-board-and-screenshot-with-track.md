`roadmap/generate.mjs` read the table but could not express the new rows, and each failure was
silent:

1. **Compound statuses fell through to To Do.** The column map keyed on exact strings

   which would have put the shipped resolve command back in the queue. Statuses now resolve by

   without a message. The pattern allows one `-SUFFIX`.
3. **The priority star had no source.** It was parsed from a `highest-ROI` line the roadmap no
   longer contains, so no card could be starred. A track the vault marks **`PRIORITY track`**
   now stars its open items; the legend and tooltip say so.
