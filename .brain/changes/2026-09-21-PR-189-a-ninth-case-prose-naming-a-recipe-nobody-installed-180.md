# PR #189 — a ninth case — prose naming a recipe nobody installed (#180)

> `test` · merged 2026-09-21 · by @Nuclominus

## Summary

Adds the ninth eval case, `evals/09-nl-unknown-recipe-warn`, with eight graders. #177 built the
dry-run eval suite but deliberately left #180 uncovered: the behaviour was still undecided — it
wanted a *warning*, not a halt — and the suite would get a case once that was settled.
[[decisions/ADR-0024-naming-a-recipe-is-an-explicit-request]] settled it and #181 implemented it,
so the case was owed. The graders assert both halves: that the warning is echoed and the
substitution named, and that nothing else fires — no agent dispatch, no phase banner, no workspace.
A warning that quietly behaved like a halt would otherwise still pass a looser check.

A second commit rode along on the same branch, unrelated to the case itself:

- **`evals/01..06` gain `Read` in `allowed_tools`.** The cases asserted on files they had no grant
  to open — the suite was measuring less than it appeared to.
- **`pipeline-orchestrator` gains a STOP rule for dry-run numbers.** Echoing `prints[]` discharges
  the obligation; the sentence *after* the preview is where it was lost. Measured in
  `evals/02-nl-preview`: a run echoed the preview verbatim, then closed with "the real expected cost
  is likely closer to ~$4.21" — a figure the resolver never produced. A second, more
  precise-sounding number contradicts a machine value and is the one a reader quotes back.
- **`android-review` gains a Duplication (DRY) section** — an extraction threshold (~60-70% shared
  structure), the four ways to parameterise the differing part, a worked Kotlin example, and a
  checklist row.
- **`CLAUDE.md` gains the PR-review-offer rule**, and `.gitignore` now excludes local `.claude`
  state. Note the `.claude/*` form: git does not descend into an excluded *directory*, so the
  directory form `.claude/` would have made the `!.claude/rules/` re-include silently fail, leaving
  CLAUDE.md `@`-including a rule file no clone would have.
- **`docs/plans/`** carries the journal, telemetry and report from the #190 run.
