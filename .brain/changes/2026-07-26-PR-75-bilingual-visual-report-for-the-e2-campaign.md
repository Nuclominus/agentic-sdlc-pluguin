# PR #75 — bilingual visual report for the E2 campaign

> `docs` · merged 2026-07-26 · by @Nuclominus

## Summary

Adds `bench/report/` — a self-contained, bilingual (EN / УКР) visual report of the E2
read-discipline benchmark campaign: the browser-viewable twin of `bench/RESULTS.md`. Open
`bench/report/e2.html` directly in any browser; no external resources, light/dark aware, with a
language toggle that switches all prose, chart annotations, tooltips and screen-reader labels.

The page tells the campaign's story as what it was — a null result with valuable side-yield —
across nine sections: the verdict (with the −10.65% delta tile **visually fused** to its
55.6–64.2% within-arm spread so neither can be quoted alone), the method and run order, per-run
strip plots of cache-read and peak prefix, the convergence-to-null replay, the peak-ceiling
hypothesis with its ≈21%-by-chance caveat at equal visual weight, the noise-floor lessons with the
dissolved-bimodality scatter, the four defects, and the recommendation. `a-4` is plotted but marked
excluded everywhere it appears; no p-values and no "significant" anywhere.

Three properties worth keeping:

1. **The page cannot silently drift from the record.** `build.mjs` recomputes every statistic from
   `bench/results-headless/*.json` with the instrument's own `median`/`spread`/`runMetrics`
   (imported from `bench/compare.mjs`, which delegates to the AAR `metrics.mjs` SSOT) and asserts
   all 35 numbers named in RESULTS.md — the build exits nonzero on any mismatch. `e2.html` is
   committed build output by design, so the report is viewable without running anything.
2. **The convergence chart is computed, not transcribed.** Replaying cumulative delta-of-medians in
   `prepared_at` order reproduces RESULTS.md's seven live readings — but only if `a-4` sits in the
   medians for the early readings, which dates the readings to before the exclusion decision. The
   chart plots the consistently a-4-excluded replay (final −10.65%) and the caption states the
   relationship to the verbatim verdict's −11.9% instead of smoothing the discrepancy over.
3. **The enrichment survived an adversarial pass.** A 3-lens verification (numbers vs. RESULTS.md,
   scientific-honesty audit, accessibility audit) ran against the page before merge; all 16
   findings — including a wrong −11.9% attribution, a scatter cluster box that excluded one of its
   own four runs, and unnamed keyboard tab stops — were fixed in the merged version.
