# PR #77 — G1 self-healing compiler/lint micro-loops

> `feat` · merged 2026-07-27 · by @Nuclominus

## Summary

Adds **G1 — self-healing micro-loops** to the pipeline orchestrator: after any guarded phase, the orchestrator runs the active profile's compile/lint `heal_checks`; on failure it re-dispatches the phase's own agent with the tool output (max `heal.max_attempts`, default 2), instead of letting broken code ride to the end of the pipeline or leak into review rounds.

Mechanics: a `heal:` workflow primitive keyed on **exit codes** (sibling of `loop:`, which is keyed
on prose verdicts); step 3b-0 snapshots the pre-dispatch tree so step 3e-heal's orchestrator-side
guard (4a) can classify failures whose diagnostics all name files outside the phase's own touched
set as `pre-existing` at **zero attempt cost**; checkpoint fields `heal_attempts_used` /
`heal_status` (`healed | exhausted | skipped | pre-existing`) flow into AAR metrics, the cross-run
rollup, and the HTML report. Dry-run cost preview gains heal terms gated on non-empty
`heal_checks` (inert `heal:` blocks on vanilla stacks price at $0 and print `⚙ Healing inactive`).
Rollout: android workflows guard `development`/`qa` with compile-only checks (perf tax trimmed
7→5 and 11→7 gradlew invocations); `analysis` cap 0.30→0.75 and `hotfix` 0.60→1.10 (both were
self-breached pre-G1).

Validated by 8 live pipeline runs (isolated `CLAUDE_CONFIG_DIR` arms, plugin cache reinstalled per
commit). The runs themselves drove nine hardening commits; durable lessons now encoded in the spec
and lint suite:

- **Machine contracts live in `_telemetry.json`, not printed output** — a promised verbatim abort
  marker failed 3/3 across three phrasings while `aborted_at_phase` held in every run; headless CI
  gates on `jq -e '.aborted_at_phase != null'`. A skill prompt also cannot set the host exit code
  or write its stderr (both observed), and a doc-wide lint test now bans promising either.
- **`total_cost_usd` = phases + `orchestration_overhead`** (overhead ran $0.84–1.17 vs $0.28–0.51
  phase spend), `null` — never `0` — when nothing is priced; the cost cap deliberately gates
  **phase spend only**.
- **Model registry**: `opus` tag repointed to `claude-opus-5` (sessions were served by it while the
  registry still said 4-8 → null costs); `opus-4-8` kept pin-only so history stays priceable.
  `lookupPricing` strippers reordered prefix-before-date so the one dated registry key
  (haiku) stays reachable from Bedrock-shaped ids (PR #77 review finding).

Known gaps, declared not hidden: `healed`/`exhausted` branches have test-only evidence (no live run
produced in-scope breakage); `-p` without `SDLC_NONINTERACTIVE` is nondeterministic at the dev
planning gate (HEADLESS detection rests solely on the env var — open design decision); parallel
group members cannot carry `heal:` (schema allows strings only in `parallel:`).
