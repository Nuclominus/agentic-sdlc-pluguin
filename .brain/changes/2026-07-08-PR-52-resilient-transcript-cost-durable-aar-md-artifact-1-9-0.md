# PR #52 — resilient transcript cost + durable _aar.md artifact (1.9.0)

> `feat` · merged 2026-07-08 · by @Nuclominus

## Summary

Run `brain-rudderstack-phase-c` shipped with `$—`. The orchestrator recorded each phase's `agent_id`
in `.checkpoint/*.json` but **not** in `_telemetry.json`, so transcript-derived cost enrichment
(which keys phases to transcripts by `agent_id`) skipped every phase. The transcripts were intact —
a `--session` backfill recovered **$18.01** (+ $8.99 orchestration overhead). This PR fixes the
plumbing so it can't recur, and makes `/sdlc:aar` leave a durable artifact.

## Changed areas

- [[components/sdlc]] — `tools/usage` (checkpoint `agent_id` fallback, no-clobber guard,
  shared-transcript dedup, suffix-tolerant pricing), the `sdlc:aar` skill (persists `_aar.md`).
- [[architecture/pipeline-orchestrator]] — Step 5b auto-resolves `--session` + verifies `cost_basis`
  flipped; Step 3d-1 makes per-phase `agent_id` in `_telemetry.json` mandatory.

## Decisions & rationale

- Implements [[decisions/ADR-0006-aar-report-artifact]] — `/sdlc:aar` now persists the review to
  `docs/plans/{slug}/_aar.md` (durable + discoverable); the analyst stays read-only, the main session
  writes the file, and the trigger stays user-only.
- Hardens [[decisions/ADR-0005-transcript-derived-cost]] (see its 2026-07-08 addendum) — the

  prices a resumed subagent's shared transcript once, and tolerates model-id suffixes.
