## Decisions & rationale

- No ADR: a presentation change plus repo hygiene, with no effect on how a plugin resolves or runs.
- The pipeline diagram shows the gated `remediation` phase as a dashed "Fix, only if High+" node.
  The first draft left it out; review caught it, because the caption names `android-feature.yaml`,
  which runs that phase.
- SVG text uses system fonts. GitHub does not load web fonts inside an `<img>`, so the banner varies
  slightly by OS.
- Lesson for local files: once a path is in `.gitignore`, git treats an untracked file there as
  disposable. Pulling a commit that deletes the tracked copy also deleted the untracked local
  `docs/plans/_journal.md` (with one unpushed entry). It was restored by hand. Copy such a file
  aside before pulling a change that both ignores and deletes its path.
