# PR #204 — doctor, init and list-stacks are reachable on Antigravity

> `fix` · merged 2026-09-22 · by @Nuclominus

## Summary

Antigravity's `agy plugin install`/`validate` reports `commands: 11 processed
(converted to skills)`, and the Track J emitter's design comment took that at
face value: Antigravity does the command→skill conversion itself, so nothing
more was needed. Measured against the real installed package on agy 1.2.8,
that claim is false — `agy -p "/skills"` proves only the pre-existing
`skills/*/SKILL.md` directories (`aar`, `create-pluguin`,
`pipeline-orchestrator`) were ever invocable. The 11 `commands/*.md` files
get copied byte-identical into the install, but nothing on the host maps
them to a callable skill or slash command. A live pipeline run on
`parlor-android` hit this directly: the resolver's own legacy-location
`WARN:` told the user to run `/sdlc-doctor`, a command that could not be
invoked on that host at all.
