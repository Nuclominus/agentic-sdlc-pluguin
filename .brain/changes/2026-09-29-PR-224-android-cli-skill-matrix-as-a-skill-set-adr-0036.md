# PR #224 — Android CLI skill matrix as a skill set (ADR-0036)

> `feat` · merged 2026-09-29 · by @Nuclominus

## Summary

PR 1 of 5 for making Google's Android CLI skill catalog a `policy: warn` runtime dependency of
android-foundation, the same level as superpowers, with a per-role skill matrix. This PR adds the
data and the lint check; nothing reads the matrix at run time until #225.

- `plugins/android-foundation/skill-sets/android-skills.yaml` triages all 25 catalog skills into
  13 categories that follow the upstream folders.
  - Each category lists the only roles its skills may reach (the scope guard), so the
    security-analyst can never be given a UI skill.
  - Rows are bare ids, `recommended` by default. The only `mandatory` rows are
    `android-intent-security` and `android-permissions-security` for the security-analyst.
  - Library-specific skills (CameraX, Billing, Wear, …) are gated by `applies_if`.
- `schemas/skill-set.schema.json` defines the file format.
- The skills × roles table (`android-skills.md`) and a per-role README block are generated from
  the YAML.
- A new `sdlc-lint skill-sets` verb validates the schema, the scope guard, the run-scoped `when`
  wording and leftover `TRIAGE` markers. It fails when the generated views are stale, and
  `--write` regenerates them.
- The `android-skills` entry in `runtime-dependencies.json` was added, still inert.
- Review fix: the `agp-9-upgrade` gate now recognises AGP declared as a version-catalog key, a
  buildscript classpath or through the plugins DSL.
