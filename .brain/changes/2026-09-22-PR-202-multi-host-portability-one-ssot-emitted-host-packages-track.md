# PR #202 — Multi-host portability: one SSOT, emitted host packages (Track J)

> `other` · merged 2026-09-22 · by @Nuclominus

## Summary

Track J: ship the SDLC pipeline on other agentic CLIs from one authoring surface. `plugins/**`
stays the single source of truth; a new `sdlc-lint emit` verb renders `dist/<host>/`, and
`emit --check` (wired into `all`, so CI) gates the committed output. Nothing translates at run
time. This PR merges `develop` into the long-lived `feat/sdlc-multi-host-port` branch, reconciling
two independently-evolved designs for plugin-root identity (`roots.mjs`/`plan.mjs`) into one
resolution chain, and lands the first measured Antigravity package: a real pipeline ran and sealed
on `agy`, and the emitted `dist/antigravity/` package now ships no `hooks.json` at all — measured
against a throwaway probe plugin on agy 1.2.0, the plugin's hooks are silently rejected by that
host's runtime even though `agy plugin validate` passes them, so shipping a hook nobody can fire
would have been a worse failure mode than shipping none.

## Changed areas

- `plugins/sdlc/tools/resolve/` — `roots.mjs` and `host.mjs` gained a declared-host fast path
  (`config/host.json`) that takes no path load from `CLAUDE_PLUGIN_ROOT`, keeping an authored
  checkout beside a `dist/` package from making the default recipe ambiguous.
- `plugins/sdlc/tools/migrate/` — the `.claude/` → `.sdlc/` legacy-location move
  (`scanLegacyLocation`/`applyLegacyMove`), reported and applied by `/sdlc:doctor` before any
  agent-name rename.
- `tools/sdlc-lint/lib/emit/` (new) — the emitter itself: `index.mjs` (render plan), `check.mjs`
  (drift gate, content/orphans/undeclared-drops), `write.mjs`, `overlay.mjs`, `models.mjs`.
- `tools/sdlc-lint/hosts/antigravity.json` — the measured host descriptor, including the hooks
  finding above and the per-script `drop_hooks` reasons.
- `dist/antigravity/` (new, committed) — the emitted package; regenerate with
  `node tools/sdlc-lint/cli.mjs emit`, never hand-edit.

## Decisions & rationale

- [[decisions/ADR-0029-one-ssot-emitted-host-packages]] — build-time emission from one authoring
  surface, no runtime translation layer; the rationale for shipping `dist/<host>/` as committed,
  generated, and drift-checked rather than either hand-maintaining N copies or translating at
  dispatch time.
- [[decisions/ADR-0030-the-project-sdlc-directory-is-ours]] — a project's own SDLC config moves to
  `.sdlc/`, a directory this marketplace owns, instead of living inside `.claude/`, a directory
  that belongs to one host and stops existing on every other one.
- These two ADRs were originally numbered 0022/0023 on the long-lived branch and were renumbered
  during this merge to avoid colliding with ADR-0022..0028, which landed on `develop` in the
  interim (path-loaded-plugin identity, framework-plugin embedding, `frameworks.disable`, and the
  external-dependency-declaration rule).
